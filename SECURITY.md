# Reporting a security issue

Send a description and reproduction steps to bastardcoins@gmail.com. Avoid
publishing an exploit that would put holders at immediate risk. Do not send
wallet passwords, recovery phrases, private keys or credentials.

There is no paid bug bounty or guaranteed response time. The deployed contract
has no administrator or upgrade mechanism. A report cannot be resolved by
silently changing that contract. Any response that changes the token would
require a separately disclosed proposal and user decisions.

The contract has not received an independent audit. Local tests and source
verification do not establish that the token, its liquidity pool, wallet
software or third-party interfaces are free of vulnerabilities.

Confirm the Arbitrum One contract address before using any token or pool.
No project representative needs a holder's recovery phrase or private key.
